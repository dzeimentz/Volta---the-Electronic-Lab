# ADR-0006: Keine Datenerhebung, kein Netz, keine Konten

- Status: angenommen
- Datum: 2026-10-04

## Entscheidung
Volta verarbeitet keine personenbezogenen Daten, benoetigt keinen Netzwerkzugriff und fuehrt keine Konten.
Austausch (Profile, Experimentsaetze, Fortschritt) nur per Datei oder QR-Code.

## Begruendung
- Kinder-Apps: Store-Auflagen und Elternvertrauen.
- Schulen: kein Vertrag zur Auftragsverarbeitung noetig -> erheblich leichtere Einfuehrung.

## Folgen
- Keine Telemetrie-, Absturz- oder Werbe-SDKs. Support ueber kopierbare Supportangaben und E-Mail.
