# Glossar

| Deutsch | Code (EN) | Bedeutung |
|---|---|---|
| Band | Edition | eigenstaendige App der Reihe (volta1, volta2, volta3, zuse1) |
| Grundplatte | Board | Arbeitsflaeche mit Kontaktfeldern |
| Kontaktfeld | Field | Feld mit 4 leitend verbundenen Steckplaetzen = 1 Knoten; A1–E8 |
| Steckplatz | Socket | einzelnes Loch in einem Feld |
| Leitung | Wire | frei gezogene Verbindung |
| Bauteil | Component | Typ im Katalog / Instanz auf der Platte |
| Traegerplatine | CarrierBoard | Platine fuer Bauteile mit 3 Anschluessen |
| Modul | Module | Baugruppe in der Modulleiste |
| Modulleiste | ModuleBar | Felder M1–M16 |
| Bedienpult | ControlDesk | Batterie, Hauptschalter, Regler, Lautsprecher, Messgeraet |
| Pultleiste | DeskStrip | Pultfelder +9V … LS2 |
| Gruppenlinie | GroupLine | Zugehoerigkeitslinie mit Schaltzeichen, keine Leitung |
| Lichtring | KnobRing | 270°-Segmentring um Drehregler |
| Klanganzeige | SoundRing | Leuchtring am Lautsprecher (Farbe = Tonhoehe, Helligkeit = Pegel) |
| Dreifach-Messgeraet | Meter | V, A, Ω; digital/analog |
| Spannungsanzeige | VoltageBars | 4 hellgruene Balken je Feld |
| Werkzeugkasten | Toolbox | Farbcode, Formelrechner, Lexikon, Zeitschreiber, Fehlersuche, Teileliste |
| Forscherheft | Journal | Vermutungen, Beobachtungen, Zeichnungen, Fotos |
| Forscherprofil | Profile | lokales Profil ohne Klarnamen |
| Elternschranke | ParentGate | Schutz vor Kinderzugriff |
| Erfolgsbedingung | SuccessCondition | zustandsbasierte Pruefung eines Experiments |
| Befehl | Command | undo-faehige Aufbauaenderung |
| MNA | MNA | modifizierte Knotenpotentialanalyse |
| RHI | RHI | Rendering Hardware Interface von Qt |
